# Kontrolyaut

Vytvor mi novy web ktery bude zamereny na konroly ojetych vozu pred koupi. Vytvor ho v uplne stejnem designu jako je web Stavbaterie.  Barevne ho udelej modro bily a pouzij logo v priloze. Web bude stejne jako Stavbaterie pouzivat jako BE cars-eu.cz na nam i admin menu to tam bude spolecne pro vsechny 3 weby.
